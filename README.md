 Plant Care Reminder App

A simple and beginner-friendly Plant Care Reminder App designed to help plant owners take better care of their plants.

 About the Project

Many beginners forget when to water their plants or do not know the specific care needs of each plant.

This project helps users by providing personalized plant care reminders, plant identification, and growth tracking.

 Main Features

-  Add and manage plants
-  Identify plants using photos
-  Set watering and care reminders
-  Get push notifications
-  Track plant growth with photos
-  View plant-specific care information

 Target Users

- Beginner plant owners
- Busy working professionals
- College students
- Home gardeners

 User Flow

Open App → Home → Add Plant → Identify/Search → Care Profile → Set Reminders → Growth Log
